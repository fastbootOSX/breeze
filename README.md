# Breeze
Breeze is an operating system designed for home use. It makes no difference whether you are a professional, a gamer, a casual user, a programmer, or a system administrator. Breeze features full built-in support for .exe files, so you don't have to master an entirely new environment. It is developed by me alone, not a team. Breeze offers native, out-of-the-box support for NVIDIA patches and drivers. It can be installed on any PC; simply consult the installation guide.
